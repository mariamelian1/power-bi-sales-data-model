# Sales Data Model | Power BI

## Overview
A Power BI data model built to analyze sales, inventory, campaigns, and order processing using a star schema.

## Data Model
![Data Model](data_model.png)

**Fact tables:** fact_sales, fact_inventory, fact_campaign, fact_promotion_coverage, fact_order_process, fact_sales_target

**Dimension tables:** dim_products, dim_customers, dim_geo, dim_campaign, dim_flag_orders

## Tools
Power BI, Power Query, DAX
